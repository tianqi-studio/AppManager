# 应用收纳器

一款基于 WinUI 3 原生开发的 Windows 应用管理器，遵循 Fluent Design 设计风格。

自动扫描系统开始菜单快捷方式与微软商店 UWP/MSIX 应用，支持自定义分组、标签分类收纳应用；支持一键启动程序，并提供可自定义的全局快捷键，任意界面一键唤起面板。

告别翻找开始菜单的繁琐，帮你整理电脑里繁多的应用，打造清爽、高效的应用启动工作流。

## ✨ 功能特性
- 📡 **自动扫描**：读取开始菜单快捷方式、微软商店应用，自动提取图标、名称、路径信息
- 🗂️ **分类收纳**：自由创建分类，拖拽整理应用，自定义应用分组
- 🚀 **一键启动**：点击快速启动程序，支持附加启动参数
- ⌨️ **全局热键**：自定义全局快捷键，任意窗口、桌面一键唤起收纳面板
- 🪟 **原生体验**：WinUI3 流畅界面，贴合 Windows 系统视觉风格，轻量化后台占用
